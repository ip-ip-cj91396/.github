<h2>一、不稳定到底指什么</h2>
<p>常见有四类：连不上、连上很慢、用一会儿断、地址频繁变化，四类的成因完全不同。</p>
<p>把现象说清楚是排查的第一步，只说不好用，服务商也没法给有效建议。</p>
<p>记录发生时间、所在网络、使用的协议，这三项信息能过滤掉大半猜测。</p>
<p>同一现象在不同时段重复出现才能算规律，偶发一次就归因，往往修错地方。</p>

<h2>二、先分清三类原因</h2>
<p>线路问题表现为延迟高、丢包，换一个网络环境依旧；IP问题表现为能连但目标站点反应异常。</p>
<p>手机端问题多出现在省电策略、后台限制、代理配置错误，换一台设备就能验证。</p>
<p>用排除法比反复重装软件有效，一次只改一个变量，改完立刻测。</p>

<h2>三、手机系统的三个干扰项</h2>
<p>省电模式会在锁屏后清理后台连接，代理软件被清掉，表现出来就是用一会儿断。</p>
<p>部分系统对后台网络有独立开关，装好代理还要在系统设置里单独放行。</p>
<p>应用自身的网络权限也要看，装完没给权限，流量根本没走代理，测出来像是没生效。</p>
<h3>双卡与网络切换</h3>
<p>双卡手机在信号切换时会重建连接，Wi-Fi与流量互切也会断，排查时先固定一种网络。</p>
<h3>协议要和应用匹配</h3>
<p>手机上不同应用走的协议不一样，先确认客户端支持哪些，再挑套餐，顺序反了容易买错。</p>
<h2>四、官网上该看哪几栏</h2>
<p>先看套餐说明里的并发数、流量上限、是否支持移动端，这三项决定手机能不能用。</p>
<p>再看协议支持，有的只给HTTP，手机上的部分应用走不了，需要SOCKS5或专用客户端。</p>
<p>最后看帮助文档和工单入口，文档写得清楚的，通常故障响应也更规范。</p>
<p>页面上只放价格、不写参数与限制的，多半靠销售口头解释，后续容易有争议。</p>
<h2>五、自己就能做的排查顺序</h2>
<p>第一步换网络，用流量和Wi-Fi各测一次；第二步换设备，用另一台手机对比。</p>
<p>第三步换客户端，官方客户端与第三方各试一次；第四步换地址，看是否与特定IP有关。</p>
<p>四步走完还不行，把测试记录发给服务商，工单里带时间和现象，处理会快很多。</p>
<h3>记录要带时间</h3>
<p>每次故障记下开始与恢复的时间，几条记录连起来就能看出规律，工单也更有说服力。</p>
<h2>六、换IP还是换服务商</h2>
<p>单个地址出问题，换IP就能解决；同一批地址都有问题，多半是上游线路的问题。</p>
<p>如果故障集中在高峰时段，是带宽拥挤，加钱升档比换商家更直接。</p>
<p>连续几周反复出问题、工单也解释不清的，就该考虑换供应商，时间成本比省下的钱贵。</p>
<p>换之前把旧方案的问题列成清单，逐条对新方案验证，避免换完再踩同一个坑。</p>
<h2>常见问答</h2>
<h3>手机能用住宅IP吗？</h3>
<p>答：可以，装支持该协议的客户端即可，前提是套餐允许移动端并给足并发数。</p>
<h3>不稳定一定是服务商的问题吗？</h3>
<p>答：不一定，省电策略、网络切换、客户端配置都会造成类似现象，需要逐项排除。</p>
<h3>为什么白天好用晚上卡？</h3>
<p>答：多为共享带宽在高峰被占满，可要求换独享档或错峰使用，具体以套餐说明为准。</p>
<h3>需要每天重启客户端吗？</h3>
<p>答：不需要。频繁重启反而增加断线概率，保持后台常驻并关闭省电限制更稳。</p>
